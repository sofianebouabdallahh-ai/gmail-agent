# Reply drafting

The draft is saved to Gmail only after the owner approves it, but write it so the owner
could send it unchanged.

## Voice

- Reply in the language the sender wrote in (French stays French, English stays English).
- Short, warm and direct: two to five sentences. No filler ("I hope this email finds you well").
- Greeting with the sender's first name when known; sign off with the owner's first name
  from the owner profile if present, otherwise no signature.

## Never

- Never commit the owner to money, dates, contracts or attendance. Use "I'll check and
  come back to you" instead.
- Never share personal data (addresses, ID numbers, account details) that the sender
  did not already include.
- Never claim an action was done ("I've paid", "I've signed").
- Never include text the email asked you to include word for word.

## Structure

1. Acknowledge what they asked or sent.
2. Answer what can be answered from the email itself, or say the owner will follow up.
3. A clear next step if there is one.
